# Arthur Fachel

Data Science student at PUCRS and researcher at [MALTA Lab](https://malta-lab.github.io/), Porto Alegre. I work on LLM evaluation and continual learning.

## Research

**The Role of Contextual Grounding in Geoscience Benchmarks**, BRACIS 2026<br>
Self-conditioned prompting on GeoBench: queries get a structured reasoning layer (domain, geological process, difficulty) before the model answers. Evaluated on 4 open-source LLMs. Joint work with Petrobras and UNISINOS.<br>
[Paper](https://doi.org/10.1007/978-3-032-39898-7_39) · [Code](https://github.com/ArthurFachel/Contextual-Grounding)

**Who moved continual learning to LLMs?** (2026)<br>
Reproducible bibliometric study on OpenAlex: US industry seeded continual learning for LLMs, China scaled it.<br>
[Report](https://github.com/ArthurFachel/cl-bibliometrics/blob/main/docs/report.pdf) · [Code](https://github.com/ArthurFachel/cl-bibliometrics) · [DOI](https://doi.org/10.5281/zenodo.23525601)

**Neuron-level plasticity for continual learning** (ongoing)<br>
Per-neuron functional importance decides which units stay plastic between tasks, plus activation-level competition.<br>
[Code](https://github.com/ArthurFachel/dual-heater-mlp)
